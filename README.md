# Project Toolkit — Mini Python Utilities

Quick hook: A compact collection of helpful Python tools — Mindset, Password Meter, and Unit Converter — ready to run, learn from, and extend.

This repository contains three small, well-documented Python utilities designed for learning and quick practical use. Each tool is independent, tested to run with Python 3.8+, and comes with clear examples so you can run them immediately or integrate into larger projects.

Contents

Mindset — a simple interactive notebook/script for guided daily prompts, habit tracking ideas, or short journaling (Jupyter-friendly).

Password Meter — checks password strength, gives a readable score and suggestions to improve.

Unit Converter — flexible CLI and Python-module based unit conversion (length, mass, temperature, volume, and time).

Features

Lightweight, zero-dependency Python code (standard library only) — optional extras listed for enhancements.

Clear CLI interfaces and importable modules so you can use the functions in other projects.

Jupyter notebook support for Mindset so you can run and edit cells interactively.

Human-friendly outputs and actionable suggestions (e.g., how to improve a weak password).

Example inputs/outputs included for quick testing.
